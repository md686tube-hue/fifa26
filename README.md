# 🏆 FIFA World Cup 2026

বাংলাদেশ সময় অনুযায়ী FIFA World Cup 2026 এর সম্পূর্ণ সময়সূচি, গ্রুপ তথ্য এবং দলের স্কোয়াড।

## Features

- 📅 সম্পূর্ণ গ্রুপ পর্বের ম্যাচসূচি (বাংলাদেশ সময় GMT+6)
- 🏟️ ভেন্যু ও শহরের তথ্য
- 👕 দলের স্কোয়াড তালিকা
- 🔍 দল ও গ্রুপ ফিল্টার
- 📊 গ্রুপ স্ট্যান্ডিং

## Tech Stack

- React 18
- Vite
- CSS-in-JS (inline styles)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
